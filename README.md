# Assignment-1: Personal Portfolio Web Application

Built with HTML5, CSS3, Bootstrap 5 and JavaScript ES6+.

## Requirements covered
- Semantic sections: Home, About, Education, Skills, Projects, Achievements, Contact
- Headings, lists, links, table, form and accessible labels
- CSS3 selectors, box model, typography, Flexbox/Grid and media queries
- Bootstrap navbar, grid, cards, buttons, table, forms and alerts
- JavaScript arrays/objects, ES6 variables, arrow functions, conditions, loops and DOM manipulation
- Interactive project filtering
- Dark/light theme switching with localStorage
- Project detail event handling
- Client-side form validation with dynamic success/error messages
- Responsive and accessible design

## Run
Open `index.html` in a browser.

## GitHub Pages
Upload the whole folder to a GitHub repository, then enable Pages from Settings > Pages using the main branch and root folder.

## Before submission
Replace `Your Name`, college/school information, education details and project/achievement details with your actual information.
